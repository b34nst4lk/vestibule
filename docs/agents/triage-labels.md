# Triage Labels

| Label | Purpose |
|-------|---------|
| `needs-triage` | New issue awaiting categorization and scoping |
| `needs-info` | Blocked awaiting user input or clarification |
| `ready-for-agent` | Clear, scoped, ready for autonomous agent work |
| `ready-for-human` | Ready for human review or action |
| `wontfix` | Explicitly not doing — issue closed with rationale |

## Usage

- Apply `needs-triage` to all new issues
- Move to `ready-for-agent` once the issue is clear and actionable
- Use `needs-info` when blocked on external input
- Mark `wontfix` with a brief explanation in the issue body or resolution comment
